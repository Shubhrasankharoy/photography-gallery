# Project Rules

- Use JavaScript only.
- Use Next.js App Router.
- Never use TypeScript.
- Never change completed components unless requested.
- Reuse existing components.
- Keep styling in Tailwind CSS.
- Use Firebase Authentication.
- Use Firestore.
- Use Google Drive for image storage.
- Make every page mobile responsive.
- Use server components where appropriate.
- Validate every form.
- Keep folder structure clean.
- Explain any new package before installing it.
